Claude Code mods

Run every Claude Code session from one tower.

Five repos, a dozen agents, one of them stuck on a permission prompt in a terminal you can't find. Tower puts every running session in one pane: who needs you, what each is doing, and a box to steer it. Answer, redirect, jump to it or launch a new one without leaving your seat.

Install the mods View on GitHub

One plugin, three parts

Install it in every session. Each session reports what it is doing through a small status file; whichever one you run /tower in becomes your control pane. Every part can be switched off in /config.

in the session you steer from

/tower pane

/tower opens a pane listing every running session on this machine, across repos, sorted so whoever needs you is on top. Pick one to send it a prompt, allow or deny what it waits on, answer its question, or jump to its window. Launch a new background agent in any repo with a task.

in every session

notifications

A desktop notification when a session needs you: a permission prompt, a question, a long turn finishing. Writes what each session is doing for the tower to read, and receives the tower's prompts and answers as if you had typed them there.

at the bottom

status line

A status line with where you are and how you run: 2 need you · folder ⎇ branch* · model · effort · mode · ctx 42% · $1.23, led by how many other sessions wait on you.

Answer from the tower, not the terminal

Sessions the tower launched send their permission prompts and questions to the tower instead of a dialog nobody is looking at. The agent is told to wait; your Allow arrives as its next prompt, and that exact call runs once.

Sessions you started by hand keep their own dialogs: the tower shows what they wait on and takes you there. Want every session steered from the tower? Set remoteAnswers to always.

  1. Agent asks to run git push origin main
  2. The plugin holds the call and flags the session
  3. You press Allow in the tower
  4. The agent retries, and that call alone goes through

In design

Next: the cockpit

A local web dashboard for when one pane is not enough: every repo and its workstreams on the left, the fleet in the middle, the selected agent's live activity on the right.

  • Workstreams. Start a git worktree per line of work, with its own branch and agents, and watch each one.
  • Fast approvals. The agent's reason, a diff preview and risk badges on every request; Allow, Always allow or Deny from the keyboard.
  • Changes and PRs. Lines changed per agent, pull request, CI and review status, merge when it's green.
  • Health. Stuck, looping and context-full agents flagged, how long each waited on you, cost caps that pause an agent.
  • Fleet control. One prompt to many agents; pause, resume or stop a whole repo; a timeline of who worked and who waited.

Install

One line: add the marketplace, install the plugin. Mods draw in a terminal (VS Code's integrated terminal works) and the desktop app's Code tab.

claude plugin marketplace add alaturqua/tower-mods && claude plugin install tower@tower

Then run /tower in the session you want to steer from. Claude Code mods are early access; the API can change between releases.
